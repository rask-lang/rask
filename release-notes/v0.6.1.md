# Rask v0.6.1

Rask can be learned from the website now. There's a tour, one idea per step,
and a tutorial that builds a small MUD over thirteen chapters. Every step and
every chapter command runs in CI, so the text and the compiler can't drift
apart. Install is one line:

```sh
curl -fsSL https://rask-lang.dev/install.sh | sh
```

v0.6.0 failed tour steps 11, 29 and 30. This release passes all of them.

## Language changes

These break code that compiled on v0.6.0.

- An ignored error is a compile error. A call returning `T or E` whose result
  is dropped has to be handled, propagated with `try`, or discarded on purpose.
- An integer literal with nothing else to go on is an `i64`.
- `T or none` is `T?`, on both backends. The interpreter used to treat the long
  spelling as a result with error type `none`.
- An explicit `.ne(x)` on a tuple, optional or link is gone. `!=` was always the
  spelling.

## New

- `OrderedMap`, a map that iterates in insertion order on every machine and in
  every mode. `Map` stays in seeded hash order (`determinism/D7`).
- A type can write its own `decode` and `encode`, and every decoder and encoder
  calls them. Private fields mark an invariant instead of constructors.
- `reflect.params<F>()` gives a function's parameters, their types and modes.
- Fork-join through tasks that borrow their frame, and staged structural
  changes on racks.
- Floats have the same bits on every machine and both backends.

## Fixes

The larger groups of bugs fixed since v0.6.0:

- Native leaks and double frees:
  fields moved out of `take` structs, closures that reassign what they
  captured, Map `clear` and `remove`, racks inside collections, and channel and
  `Shared` handles held in structs and collections.
- Native crashes: a void method called through `any`, a vector captured by
  `Thread.spawn`.
- Checker: generic error unions, `with` on two elements, const floats and array
  lengths, package-qualified generic calls, a recursive generic that hung, and
  `rack[h]`, which used to type-check.
- `rask` rejects unknown flags.

## Under the hood

The v0.7 work ("each fact has one owner") started here. Sizes and alignment
come from one layout model that takes the target, so `usize.MAX` is the 32-bit
value on a 32-bit target. A call says what it does to its arguments itself,
instead of later passes looking its name up in tables.

Map keys whose hashes are equal keep their insertion order, and the spec now
says so (#1939).
