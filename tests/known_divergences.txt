# --- E0361: binding whose type inference left open (#620) ---
# Empty. All 19 files that lit up when E0361 went on by default now compile.
#
# Worth knowing, because the labels on this list were wrong more often than
# right. Only four of the categories were real:
#
#   `break x` was parsed as a jump, not a value. The parser guessed from the
#   next token, so `break i` became "go to a label called i", the loop's value
#   type had nothing to unify against, and three separate workarounds had grown
#   downstream to paper over it.
#
#   A `select` arm never bound its received value, so the arm body typed `v` as
#   a free variable and that spread to the whole select.
#
#   `?? <literal>` deferred forever. An unsuffixed number never settles on its
#   own — literal defaulting does it, and that runs after the last solve, by
#   which point the deferred constraint is gone.
#
#   Closure parameters were never bound at all. The body worked on a variable
#   nobody could pin, so `map(|r| r.view.title)` couldn't type `r.view`.
#
# The rest were two other bugs wearing E0361's clothes: an operator with a bare
# literal operand (#630, seven files) and a range that carried no element type,
# so `for i in 1..6` left `i` free and every Vec it filled with it. Both
# `with`-block-as-value and `collect` were mislabelled — reduced, neither needed
# a `with` block or a `collect` to fail.
