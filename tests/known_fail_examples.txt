# Examples that do NOT yet run cleanly on both backends, so they have no golden
# in tests/golden/ and are not enrolled in tests/examples_gate.sh. Documented
# here with the tracking issue / cause. When an example runs identically on
# interp + native, generate its golden (`rask run --interp examples/<name>.rk >
# tests/golden/<name>.out`, confirm native matches) and delete its line — the
# gate then enforces it forever.
#
# Every line below carries a measured symptom and an issue. If you find one
# without an issue, that means nobody has looked; file before you assume.
#
# Re-measured 2026-08-16 (sixth pass). Changes this round:
#   - package_manager is ENROLLED. Its line said "both exit 1", which was two
#     bugs stacked. It didn't lower at all (#717): a channel created without an
#     explicit element type gave its Sender and Receiver empty type-argument
#     lists, so the two ends weren't linked and nothing `send` learned could
#     reach `receive`. With that fixed it compiled and then died with SIGILL
#     (#752): the unqualified `Io(e)` arm in FetchError.message took its tag
#     from the stdlib's IoError, which has an `Io` variant at 6, so the switch
#     keyed an arm the enum has no tag for. Byte-identical on both backends now.
#   - 16_concurrency_basics is ENROLLED, with a `sort` normalizer. The tearing
#     recorded below had two causes, not one. A single print/println call was
#     several writes (the text, then the newline), so two threads spliced
#     mid-line — fixed by locking the stream across one call, on both backends.
#     But this example also wrote each line as three separate print calls, and
#     no per-call lock can make three calls atomic; those are now one
#     interpolated println each, which is how the example should have read
#     anyway. 45 runs across both backends, one identical sorted hash. #704
#
# Re-measured 2026-08-10 (fifth pass). Changes this round:
#   - markdown_renderer is ENROLLED. Its 27 check errors were all one missing
#     method, and the method was never supposed to exist: the example was
#     mutating `string` where std.strings/S7 says only StringBuilder mutates.
#     Moving it to StringBuilder uncovered four native bugs, including a
#     compiler hang (interval widening never converged) and `match` on a char
#     matching nothing at all. Both backends are byte-identical now. #693
#
# Re-measured 2026-08-09 (fourth pass). Changes this round:
#   - game_loop is ENROLLED. The recorded "real disagreement on entity counts"
#     was a misdiagnosis: the program used an unseeded RNG, so it disagreed with
#     *itself* run to run. Seeded, it exposed two genuine bugs (SplitMix64 seed
#     expansion, and f32 arithmetic running at f64 precision in the interpreter).
#   - grep_clone is ENROLLED. The gate can pass argv now (golden/<name>.args).
#   - text_editor is ENROLLED. It was never in this file at all — no golden, no
#     line, nobody had run it. It turned up five native bugs.
#   - cli_calculator has a measured symptom instead of "reads stdin". The gate
#     can feed stdin now (golden/<name>.stdin), so that is no longer what
#     blocks it.
#   - http_api_server compiles natively now and has its own harness.
#   - 16_concurrency_basics is exit 101, not SIGABRT 134, and gets further than
#     it did.
#
# The lesson keeps repeating: re-measure before trusting a line here. A stale
# registry reads as "known broken" and nobody rechecks. Two of this round's
# enrolments were programs whose recorded diagnosis was simply wrong.
