# Open stdlib coverage gaps: what the specs promise and the stdlib doesn't yet
# deliver. tests/stdlib_coverage_gate.sh fails on a gap missing from this list,
# and on a line here whose gap has closed.
#
# Format: `<spec-id> <item> <GAP>`, as `rask stdlib-coverage --gaps` prints
# it. A trailing `# note` is allowed. v0.6 is done when this file is only
# comments.
#
#   NO-SURFACE  the spec states no `<!-- surface -->` block yet
#   MISSING     promised, not declared in stdlib/*.rk
#   PRIVATE     declared without `public`
#   UNBUILT     declared `@unimplemented`
#   MISMATCH    declared with a different signature
#   VARIANTS    an enum whose variants differ from the spec's
#   UNTESTED    built, and no suite program green on both backends calls it

std.reflect reflect.align_of UNTESTED
std.reflect reflect.is_copy UNTESTED
std.reflect reflect.size_of UNTESTED
std.strings string.span MISSING  # on a slice it has to answer the slice's range in its source, and slices are copies until #492
